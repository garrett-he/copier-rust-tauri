A [Copier](https://copier.readthedocs.io/) template for Rust projects with the
[Tauri](https://tauri.app/) framework. Generates a full-stack desktop application
with a React + TypeScript frontend and a Rust backend.

## Quickstart

1. Install the latest Copier via command:

    ```sh
    pip install --upgrade copier copier-template-extensions
    ```

2. Use command `copier` to generate a new project:

    ```sh
    copier copy gh:garrett-he/copier-rust-tauri /path/to/destination
    ```
